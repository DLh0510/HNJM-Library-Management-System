# 图书出入库管理系统

河南经贸图书馆图书出入库管理系统，支持扫码枪/手机扫码、ISBN自动查询、库存预警、批量操作、盘点、OCR价格识别等功能。

## 功能特性

- **扫码出入库** — 扫码枪或手机扫码，自动识别图书信息
- **ISBN智能查询** — 中国国家图书馆 / Google Books / Open Library 多数据源自动查询
- **手机扫码** — 无需扫码枪，手机浏览器即可扫码，支持OCR识别定价
- **库存预警** — 设置最低库存阈值，低于阈值自动提醒
- **批量操作** — 连续扫码后统一入库/出库
- **盘点功能** — 逐本扫码核对实际库存与系统库存差异
- **套装书支持** — 同ISBN多册分开管理，备注区分
- **操作员追溯** — 每次操作记录操作员和备注（系别+老师）
- **数据统计** — 首页看板显示藏书量、今日出入库、预警数
- **数据导出** — 图书列表和出入库记录导出CSV
- **自动备份** — 每小时自动备份数据库，保留最近10份

## 使用说明

### 扫码入库/出库

1. 扫码枪扫描图书条码（或手动输入ISBN按回车）
2. 已有图书 → 弹出出入库窗口，填数量和备注，点入库/出库
3. 新书 → 自动查询书名等信息，填写单价、分类、入库数量后保存

### 手机扫码

1. 点击「手机扫码」按钮，屏幕显示二维码
2. **手机和电脑必须连接同一WiFi**
3. 手机浏览器扫二维码，首次点「继续访问」信任证书
4. 点「开始扫码」对准图书条码
5. 可点「拍照识别价格」自动OCR识别定价

### 套装书（同ISBN多册）

录入时在「册/备注」字段填写册数（如"第1册"），同ISBN可录入多本。扫码时系统自动弹出选择框。

### 批量操作

连续扫码添加到列表 → 统一点「全部入库」或「全部出库」

### 盘点

逐本扫码输入实际数量 → 系统自动计算差异 → 一键应用调整

### 库存预警

编辑图书时设置「最低库存」，低于阈值时启动提醒 + 首页红色警示

## 设置

- **数据源优先级** — 可调整中国国家图书馆/Google Books/Open Library的查询顺序和启用状态
- **修改密码** — 在设置页面底部

## 扫码枪选购

- USB有线二维扫码枪，即插即用
- 推荐：得力、新大陆、霍尼韦尔，100元左右
- 无需驱动，插上就能用

- html5-qrcode (手机端条码扫描)

- GitHub Actions (CI/CD自动打包)
