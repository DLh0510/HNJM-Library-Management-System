# 图书出入库管理系统 — 使用操作手册

## 一、系统简介

本系统用于图书的出入库管理，支持扫码枪扫码、手机扫码、ISBN自动查询、库存预警、批量操作、盘点等功能。适用于学校图书馆、阅览室等场景。

## 二、安装与启动

### Windows 用户
双击 `图书出入库管理系统.exe` 即可运行，无需安装 Python 环境。

### 源码运行
```bash
pip install ttkbootstrap flask cryptography qrcode pypng requests pillow
python app.py
```

## 四、主界面

登录成功后进入主界面，顶部从左到右依次为：

- **扫码输入框** — 扫码枪扫码或手动输入ISBN后按回车
- **功能按钮** — 设置、备份、导出、图书列表、出入库记录、分类管理、库存预警、批量操作、盘点、手机扫码

### 统计看板

主界面中部显示五个关键指标：

| 指标 | 说明 |
|------|------|
| 图书种类 | 系统中录入的图书总数 |
| 总藏书量 | 所有图书的库存总和 |
| 今日入库 | 今天入库的图书总数量 |
| 今日出库 | 今天出库的图书总数量 |
| 库存预警 | 库存低于最低阈值的图书数（红色警示） |

### 最近出入库记录

主界面下方实时显示最近20条出入库记录，包含时间、ISBN、书名、类型、数量、操作员。

## 五、核心操作

### 5.1 扫码入库/出库（已有图书）

1. 将光标置于扫码输入框（默认自动聚焦）
2. 用扫码枪扫描图书背面条码，或手动输入ISBN后按回车
3. 系统弹出「图书出入库」窗口，显示图书详细信息
4. 输入数量，点击「入库」或「出库」
5. 操作成功后自动关闭窗口，首页记录和统计实时刷新

> 出库时如果数量超过当前库存，系统会提示「库存不足」。

### 5.2 新增图书

1. 扫码或输入一个系统中不存在的ISBN
2. 系统自动弹出「新增图书」窗口
3. 系统自动从中国国家图书馆查询图书信息并填充（书名、作者、出版社）
4. 补充填写：单价、分类、最低库存、入库数量
5. 点击「保存并入库」

> 如果自动查询未找到，可手动填写或点击「查询ISBN」重试。

### 5.3 图书列表

点击「图书列表」按钮，可查看所有图书。

- **搜索** — 输入关键词按书名/作者/ISBN模糊搜索，可按分类筛选
- **详情** — 选中图书后点击「详情」或双击，查看完整信息和出入库历史
- **编辑** — 修改书名、作者、出版社、单价、分类、最低库存
- **删除** — 删除图书及其所有出入库记录（需确认）

### 5.4 批量操作

适用于大批量图书到货或批量出库的场景。

1. 点击「批量操作」
2. 连续扫码，每扫一本自动添加到列表（可设置每本的数量）
3. 如需移除某本，选中后点击「移除选中」
4. 全部扫完后，点击「全部入库」或「全部出库」统一提交

> 未录入的图书会显示为 [未录入]，提交时自动跳过。

### 5.5 盘点

用于核对实际库存与系统库存的差异。

1. 点击「盘点」
2. 逐本扫码，输入该书的实际数量后按回车
3. 系统自动计算差异（实际数量 - 系统库存）
4. 全部扫完后，点击「应用盘点结果」一键调整库存

> 差异为正数表示多出，为负数表示缺少。

### 5.6 手机扫码

无需扫码枪，用手机摄像头代替扫码。

1. 点击「手机扫码」，屏幕显示二维码
2. 用手机浏览器扫描该二维码（手机和电脑需在同一WiFi下）
3. 首次打开会提示证书不安全，点击「继续访问」即可
4. 点击「点击开始扫码」，对准图书条码
5. 扫到的ISBN实时传到电脑，自动弹出对应窗口

#### 拍照识别价格

扫码页面下方有「拍照识别价格」按钮：

1. 点击后拍摄图书背面的定价区域
2. 系统通过OCR自动识别价格
3. 识别结果自动填入电脑端新增图书窗口的单价字段

## 六、库存预警

### 设置预警阈值

在新增图书或编辑图书时，设置「最低库存」字段。当库存数量 ≤ 最低库存时触发预警。

### 查看预警

- **启动提醒** — 程序启动时自动弹窗提醒库存不足的图书
- **预警页面** — 点击「库存预警」查看所有预警图书及缺口数量
- **统计看板** — 首页「库存预警」数字红色显示

## 七、出入库记录

点击「出入库记录」查看历史操作。

### 筛选条件

| 条件 | 说明 |
|------|------|
| 开始日期 | 格式：2026-03-25 |
| 结束日期 | 格式：2026-03-25 |
| 类型 | 全部 / 入库 / 出库 |
| 分类 | 按图书分类筛选 |

### 导出

点击「导出」按钮，按当前筛选条件导出CSV文件（包含操作员信息）。

## 八、分类管理

点击「分类管理」，可对图书分类进行：

- **新增** — 输入分类名称
- **重命名** — 选中后修改名称
- **删除** — 选中后删除（已关联图书的分类删除后，图书变为未分类）

## 九、数据管理

### 数据导出

点击「导出」按钮：

- **导出图书列表** — 包含ISBN、书名、作者、出版社、单价、分类、库存、最低库存
- **导出出入库记录** — 包含时间、ISBN、书名、类型、数量、操作员

导出格式为CSV，可直接用Excel打开。

### 数据备份

- **手动备份** — 点击「备份」按钮，立即备份数据库
- **自动备份** — 程序运行期间每小时自动备份一次
- 备份文件保存在程序目录下的 `backups/` 文件夹
- 自动保留最近10个备份

## 十、设置

点击「设置」按钮：

### ISBN查询数据源

系统支持多个数据源，按优先级依次查询：

| 数据源 | 特点 |
|--------|------|
| 中国国家图书馆 | 中文书最权威，有中图分类号 |
| Google Books | 覆盖面广，中英文都有 |
| Open Library | 开源图书数据库 |

可通过上移/下移调整优先级，启用/禁用某个数据源。

### 修改密码

在设置页面底部点击「修改密码」，输入旧密码和新密码即可。

## 十一、扫码枪说明

### 选购建议

- 推荐USB有线二维扫码枪，即插即用
- 品牌推荐：得力、新大陆、霍尼韦尔
- 价格：100元左右

### 使用方式

扫码枪插上USB即可使用，无需安装驱动。扫码枪本质是键盘设备，扫码后自动输入ISBN并按回车。

> macOS首次插入可能弹出「键盘设置助理」窗口，直接关闭即可。

## 十二、常见问题

**Q：扫码后没有反应？**
A：确认光标在扫码输入框内。扫码枪需要输入框获得焦点才能输入。

**Q：ISBN查询不到图书信息？**
A：部分冷门图书可能不在数据库中，需手动填写。可在设置中启用多个数据源提高查询成功率。

**Q：手机扫码打不开摄像头？**
A：需要HTTPS才能调用摄像头。首次访问时点击「继续访问」信任证书。建议使用系统自带浏览器（Safari/Chrome）。

**Q：OCR识别价格不准？**
A：尽量拍清晰，对准定价区域。识别结果可在电脑端手动修正。

**Q：数据库文件在哪里？**
A：程序目录下的 `library.db` 文件。备份文件在 `backups/` 文件夹。
